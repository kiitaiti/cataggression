## 参考サイトの確認
https://team-onyx.co.jp/ を PC 幅 1440px・スマートフォン幅 390px でヘッドレス Chromium から取得し、全画面スクリーンショットで確認しました。
応用した特徴: 白背景 + 巨大な斜体の英字見出し（2 語目をアクセント色 / 白抜き）、ダッシュ付きの小さな英字ラベル、
斜めに切った平面図形と平行四辺形のボタン、ファーストビューの Divisions / Players 等のファクト行、
白カード + 薄いグレーの画像面によるメンバー一覧、「Slot Open」型のスポンサー募集枠、黒背景 + アクセント色の斜面による CONTACT 帯、黒いフッター。
ロゴ・文章・写真・スポンサー・コードは流用していません。

## 機能（自動テスト 33 項目、全て PASS）

- Hero に canvas / WebGL が無い、タイトルが 2 行で途中折り返し無し
- カスタムカーソル: PC で初期化、タッチ / reduced-motion で無効
- 部門タブ: 初期 STREAMERS、クリック・矢印キー・Home / End
- よわいが STREAMERS 先頭、VALORANT の並びと X リンクが一致
- **メンバー画像 12 点が実際に読み込まれ、N4YUT4=02 / findingnimo=01 など指定どおりのファイルが表示される**
- リンクの入れ子なし、メンバー詳細（title / 視聴ボタン / フォローボタン）、ニュース一覧・0 件表示、404、sitemap、robots、privacy、revalidate の認証
- モバイルメニュー: 開閉、Esc、フォーカス移動 / 復帰、背面スクロール停止、タッチスクロール可
- reduced-motion で全コンテンツ表示
- WebGL 無効環境でも通常表示（WebGL を使用していないため）
